# Model routing and availability

This setup installs no API router and sends no paid model requests. `scripts/ai-development/control.py route` is a dry-run adapter: it returns a proposed provider and preflight, and never launches a CLI. Provider adapters are the installed native `codex` and `claude` executables. Unknown providers and exceeded recorded budgets fail closed. Cross-provider fallback is a coordinator decision, not automatic behavior.

Observed WSL clients: Codex 0.156.1; Claude Code 2.1.282. Existing user configuration chooses `gpt-6.1-sol` and Claude `opus`; a Sonnet effort setting is also present. These are observed configurations, not entitlement or successful inference evidence. The current desktop session exposes GPT model families through its native agent tools, which does not establish that WSL CLI accounts share those entitlements. Cached/bundled catalogs describe candidates, not account availability. Do not copy subscription credentials or enumerate secret files to establish availability.

`codex debug models --bundled` was executed without inference. Visible catalog candidates: `gpt-6-astra`, `gpt-6-sol`, `gpt-6-luna`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`, `gpt-5.5`. The configured `gpt-6.1-sol` is absent from this bundled visible list; no compatibility or entitlement claim is made for it. `codex login status` confirms ChatGPT account mode. Claude aliases observed in settings remain unverified account candidates. No fallback inference was executed.

Mechanical tasks use deterministic scripts first. Normal implementation uses an account-verified coding model; architectural and security decisions use a verified high reasoning model. Security review should use another model family when both accounts are verified. After repeated failure, increase reasoning/context or ask for a specialist review; never weaken authorization tests to save usage. Prefer inherited CLI models until quota, billing and access are confirmed. Missing model, authentication or quota is a blocker; never silently fall back to a billable API.

`scripts/ai-development/routing.json` carries conservative budgets and an explicit false `automaticPaidSpending` flag. This flag is policy metadata, not an API firewall. Model aliases are not hardcoded into native role files. CLI options and current model catalogs must be checked before selecting a concrete alternative.

Native agents and configuration follow [Claude subagents](https://code.claude.com/docs/en/sub-agents) and [Codex subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents), with installed CLI parsing treated as the compatibility check. Successful inference/fallback has not been tested to avoid new API spending. Subscription identity and extra-usage payment controls remain unverified.
