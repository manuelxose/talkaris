# Cost controls

The local SQLite ledger is `<shared Git common directory>/talkaris-ai/usage.sqlite3`, ignored with the existing local-only `.agentic` configuration. Run `python3 scripts/ai-development/control.py status`. Default recorded-usage budgets are $20/month, $2/task and $5/agent, with warning at 80%; edit `scripts/ai-development/routing.json` deliberately. `paused: true` makes route proposals fail. Provider quota failures require coordinator intervention; automatic API fallback and automatic paid spending are disabled by policy.

Record an event with `python3 scripts/ai-development/control.py record event.json`. Required fields: `provider`, `model`, `agent`, `task`, `milestone`, `input_tokens`, `output_tokens`, `cached_tokens`, `estimated_usd`, `billed_usd` (null when unknown), `retries`, `failures`. Counts must be nonnegative integers. Use actual billed cost when supplied by a provider; otherwise clearly label an estimate. Never record fake zero-token usage as proof of model accounting. Test events are stored in temporary databases and deleted.

Monthly totals use UTC timestamps and billed cost when available, otherwise estimates. Task and agent budgets are conservative lifetime totals of the local ledger. Manual ledger recording does not observe unrecorded requests, reserve future usage, enforce account limits, or prevent direct CLI calls. No hard monetary enforcement is claimed. Before live work, verify provider-side spending/extra-usage controls and distinguish subscription allowance from API billing. A coordinator must approve the cost estimate before any newly billable evaluation. Claude's supported `--max-budget-usd` is an additional API-mode control, not proof of subscription billing isolation.

No prices are embedded because no rate schedule or entitlement was validated. Usage can be imported from actual CLI/provider reports using the event schema; automatic import is not implemented. A missing cost remains unknown, never silently zero. Do not put prompts, customer content or credentials in accounting events.
